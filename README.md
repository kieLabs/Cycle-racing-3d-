# Extreme Cycle Rush 3D — Downhill & Off-Road Racing

A complete, self-contained 3D Downhill Cycle Racing Web Game built with **HTML5, CSS3, Vanilla JavaScript, Three.js, and Web Audio API**.

## Key Features
- **10-Rider Competitive Racing:** Race against 9 realistic global cyclists with 3D floating nameplates, country flags, and live ranks above their helmets.
- **Dual Camera Views (`[C]` Button):**
  1. **First-Person Handlebar POV:** Features 3D handlebars, gloved hands, brake levers, and a working stem-mounted speedometer.
  2. **Third-Person Chase View:** Shows the full articulated 3D cyclist pedaling, leaning into turns, and hitting wooden jump ramps.
- **3 Playable Mountain Biomes:** Alpine Forest, Snowy Mountain Peak, and Canyon Desert Dunes.
- **Zero External Assets:** All 3D models, textures, tracks, and sound effects are generated procedurally inside `index.html`.

## How to Deploy on GitHub Pages
1. Extract this `.zip` archive.
2. Upload `index.html` and `README.md` to your GitHub repository.
3. Go to **Settings > Pages**, select your `main` branch, and click **Save**.
4. Embed your live GitHub Pages URL inside any responsive `<iframe>` on Blogger or play directly in the browser!
