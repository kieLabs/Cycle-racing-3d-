# Extreme Cycle Rush 3D — v2 (10 World Tour Locations + Screen Orientation Fix)

A complete, self-contained 3D Downhill Cycle Racing Web Game built with **HTML5, CSS3, Vanilla JavaScript, Three.js, and Web Audio API**.

## What's Fixed & Upgraded in v2
1. **Screen Upside-Down / Inverted Camera Fix:** Strictly locked `camera.up.set(0, 1, 0)` and removed post-`lookAt` Euler roll corruption, plus set cyclist root rotation order to `YXZ` and corrected Left/Right screen-space steering.
2. **10 Distinct Playable World Tour Locations:**
   - 🌲 **1. Alpine Forest** (Pine Woods & Dirt Jumps)
   - 🏔️ **2. Snowy Glacier** (Icy Slopes & Slalom Flags)
   - 🏜️ **3. Red Rock Canyon** (Desert Dunes & Cacti)
   - 🌸 **4. Cherry Blossom** (Kyoto Pink Petal Ridge)
   - 🌋 **5. Volcano Magma** (Obsidian Trail & Lava Glow)
   - 🌃 **6. Cyber Neon City** (Night Synthwave Highway)
   - 🏝️ **7. Tropical Beach** (Palm Coast & Golden Sand)
   - 🍂 **8. Autumn Maple** (Golden Foliage Valley)
   - 🌿 **9. Amazon Rainforest** (Misty Emerald Temple Trail)
   - 🌕 **10. Lunar Space Dome** (Low-Gravity Crater Circuit)
3. **10 Live Riders with 3D Floating Nameplates:** Zero "AI/Bot" mentions anywhere.

## How to Deploy on GitHub Pages
1. Extract this `.zip` archive.
2. Upload `index.html` and `README.md` to your GitHub repository.
3. Enable **GitHub Pages** under **Settings > Pages**.
